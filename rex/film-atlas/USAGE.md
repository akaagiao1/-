# 片场 · FILM ATLAS 1.1

## 更新方法

1. 在 rex 模块管理中刷新/更新配套模块，确认版本为 **1.1.0**。必要时使用下方直链重新安装。
2. 清除这个模块的旧结果缓存，避免沿用1.0的20条结果。
3. 导入 **片场-FilmAtlas-v1.1.rex**，切换到新首页。你原来导入的首页不会因为模块更新而自动改变排版。
4. 打开“电影 × 剧集 / 经典长存”中的豆瓣电影 Top 250 或 IMDb剧集 Top 250，检查是否可以继续浏览第21条及之后的项目。

模块直链：
https://raw.githubusercontent.com/akaagiao1/-/main/rex/film-atlas/emby-public-lists.js?v=1.1.0

同一文件不带版本参数的旧直链也已更新，但客户端和CDN可能缓存旧版本，以实际模块版本号为准。

## 20条问题的修复

1.0模块对无服务端页数的完整列表按20条切片：首页通常只调用第一页，导致其余项目没有机会显示。旧首页卡片还固定page=1和count=20。

1.1默认使用完整榜单模式：

- v3接口一次给出完整列表时，保留全部条目。
- 接口提供total_pages时，分批、最多3个并发请求获取所有页，按原顺序合并。
- 后续滚动页返回空数组，防止整榜重复追加。
- 中途失败或异常空页会报错，避免把残缺数据当作完整榜单。
- 完整加载超过500页时明确提示使用分页模式，不默默截断。长榜单的加载耗时取决于上游响应和rex运行限制。
- 模块参数保留“分页加载”选项；仅该选项仍每次返回一页。

新首页每个榜单卡片均设置mode=all，不固定page，count使用原参考包已有的0。0在各版本rex中的实际显示行为仍需实机确认；它不是已验证的跨端无限显示保证。

完整指源TMDB列表实际包含的全部条目，不会为了凑250而生成内容；源榜单若暂缺影片，以实际数据为准。标为“Top 20”的豆瓣分类榜上游本来就只有约20项，完整加载不会把它变成Top 250。

## 新首页

同样的143个公开榜单，没有新增流媒体平台数据。

首页前部成对展示：

- 电影/剧集本周趋势。
- 电影/剧集口碑榜。
- 豆瓣电影Top 250 / IMDb剧集Top 250。
- 动画电影 / 动画剧集。
- 大陆、美、日、韩剧近期热门入口。

之后先展示各地区剧集详细目录，再进入六个梯队与电影类型目录。共52个区块、157张卡片，其中156张榜单卡片覆盖143个独立列表，另1张为原生观看进度。

“全平台”按你的意思指 iPhone、iPad、Mac、Apple TV 的rex客户端。首页继续使用原生banner、stack和观看进度样式及相对网格参数，没有按设备分叉数据源。**尚未在iOS/iPadOS/macOS/tvOS上分别实机验证**，不能据此保证各端显示完全相同。

## 验证

真实模块直链匿名HTTP 200，下载内容与本地1.1.0逐字相同。原有9组测试与新增5组完整加载测试通过，涵盖模拟250部电影、13页250部剧集、显式分页、中途失败和异常空页。156张卡片的模块ID、函数、参数与请求路径核对通过，143个列表保留。

浏览器预览在桌面和390px宽度下的筛选、搜索及布局检查通过。它是示意，不是rex截图；HTML配色、字体和交互不会导入rex。

未用真实用户TMDB凭据逐项验证所有源列表，也未验证四类设备的原生渲染、自动安装、长榜单超时或播放。实际数据和设备限制需要rex内检查。

## TMDB与播放

默认使用rex内置TMDB服务。可选填写自己的TMDB v3 API Key，支持404时回退v4。不要把密钥写入公开文件。本模块提供榜单和内置TMDB详情；播放继续使用你已有的资源服务。
